# Network Security Scan Project

## Overview
This project uses Nmap to perform a local network scan and identify active devices, open ports, and running services.

## Tool Used
- Nmap (Network scanning tool)

## Objective
To understand how network reconnaissance works and how attackers identify exposed services on a network.

## What I Did
- Scanned local network (10.0.2.0/24)
- Identified active hosts
- Detected open ports and services
- Documented scan results

## Key Findings
- Multiple devices detected on the network
- Open services such as HTTP, SMB, DNS identified
- Local host showed no exposed services

## Skills Demonstrated
- Network scanning
- Basic cybersecurity analysis
- Service detection
- Report documentation

## File Included
- scan_results.txt (raw scan output)

## Disclaimer
This project was done in a controlled local environment for educational purposes only.

## Additional Scans

- fast_scan.txt → Quick scan using Nmap (-F) to identify commonly open ports
- scan_results.txt → Detailed scan using Nmap (-sV) for service detection
